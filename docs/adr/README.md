# ADRs — Architecture Decision Records

Una ADR por decisión que costó tomar. Numeradas, nunca se editan: si cambia la decisión, se crea una nueva que reemplaza a la anterior.

Copiar `0000-plantilla.md` → `NNNN-titulo-corto.md`.

Las decisiones de producto se firman en Relevo (tarjetas de tipo Decisión del proyecto OPR). La ADR registra la consecuencia técnica y enlaza la tarjeta; no copia su discusión.

Este repo es público: una ADR no nombra hosts, IPs, cuentas, personas de PINCH ni datos de clientes.
